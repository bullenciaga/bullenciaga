# Security policy

Please report suspected vulnerabilities privately to `contact@bullenciaga.com`.

Do not open a public issue containing:

- private keys, seed phrases, wallet keypairs, or signing material;
- API keys, bot tokens, webhook secrets, or authentication headers;
- undisclosed administrative endpoints or exploit instructions;
- personal wallet attribution that is not already intentionally public.

Public source does not imply that every public deployment is trustworthy. Verify the domain, token mint, transaction instructions, and release hash before signing any transaction.
