# Integrated House release

The public website reads the shared House Object burn registry at
`https://bullensaga.com/api/house-objects/burns`. The homepage, statistics,
chart and curve views use that same registry instead of maintaining separate
inventory counters.

The public site contains presentation code and public verification material.
Signing, fulfillment, credential management and operational release procedures
belong to the separate private services and are not part of this repository.
