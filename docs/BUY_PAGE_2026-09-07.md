# Standalone buy page — review candidate

`/buy` replaces the Pump.fun 302 with a responsive public page. It has a House-styled integrated Jupiter swap (SOL input, canonical BULLEN mint fixed, no preset amount, autoConnect false), seven wallet routes using the existing wallet registry, direct Pump.fun/Jupiter links, contract copy and a canonical share link. The shared navigation gains Buy under Market and in the mobile directory. Existing home/Tape/Drop modal behavior is preserved.

Phantom uses the existing native CAIP-19 swap link. Solflare uses the owner-confirmed native token page followed by Buy. Other wallets reuse the public chooser's existing browse links; detected providers continue to the embedded swap instead of launching another app. No page code calls connect/sign/trade. Jupiter retains its own token warnings and wallet approval flow.

Market context uses `/volume`, `/supply` and `/ohlcv?tf=24h|7d`. Circulating cap and FDV are separately derived from price and matching-mint on-chain supply. Missing fields stay unavailable; delayed snapshots are labelled. Chart points use timestamps, exclude invalid/duplicate/out-of-range samples, and isolate overlapping requests. No invented market fixtures are shipped. Refreshes run once per minute while visible.

## Validation

- `npm test` — repository suite.
- `CHROMIUM_PATH=<Chrome executable> PLAYWRIGHT_MODULE=<Playwright index.mjs> node qa/test-buy-page.mjs` — eight isolated scenarios including 320/375/390/430/820/1440 widths, seven wallet destinations, exact mint/amount configuration, clipboard, chart visibility/range, cap versus FDV, in-wallet continuation without a connect call, plugin failure/retry, API failure and no-JS links. External wallet/trade requests blocked.
- Real disconnected Jupiter loaded in desktop and phone Chrome; SOL / BULLEN visibly selected, House theme, no horizontal overflow, no page errors. No wallet connected, no amount entered, no signature, quote execution or transaction.
- Native iOS/Android wallet launch is not certified by desktop emulation; the existing confirmed Phantom/Solflare route logic is reused.

Preview: `node qa/serve-buy-preview.mjs --serve` prints a localhost URL. The preview proxies only the three read-only public feed paths, serves canonical website files, and never deploys anything.
